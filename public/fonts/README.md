# Bundled fonts

Latin variable WOFF2 assets from pinned Fontsource packages:

- `@fontsource-variable/geist@5.3.0`: Geist, normal weight axis.
- `@fontsource-variable/geist-mono@5.3.0`: Geist Mono, normal weight axis.
- `@fontsource-variable/fraunces@5.3.0`: Fraunces, normal and italic weight axes.

Files are renamed only for concise asset URLs. Each upstream SIL Open Font License
is included next to its assets. No font service is contacted by the app or its build.
